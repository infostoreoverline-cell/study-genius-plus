## Limiti o problemi rimasti
1. **Frontend App**: Il ciclo vitale lato Client (React/Browser) è disaccoppiato in questa repository, che costituisce principalmente un API layer/backend. Serve la GUI per completare l'esperienza.
2. **TypeScript Strictness**: Alcune migrazioni dalla vecchia repo (es: parser PDF o Renderer SVG) hanno importazioni che violano `verbatimModuleSyntax` in `tsconfig.json`. La compilazione fallisce su quei file in modalità strict. (TS1484, TS2532 null-checks non rispettati su `packages/visual/tests/visual.test.ts`).
3. **E2E reali**: Non è possibile, attualmente, instanziare `test:e2e` veri poiché la UI è non completata (messa a placeholder nel `package.json`).
