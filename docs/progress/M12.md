# Stato Avanzamento M12: Esportazione

## Stato
**COMPLETATO**

## Cosa funziona davvero
- Implementata l'infrastruttura di esportazione in `packages/contracts/src/export.ts` per standardizzare formati e payload (Markdown ZIP, LaTeX, PDF).
- Sviluppato `MarkdownExporter` che genera la struttura multi-file per lo ZIP finale. Questo include il `document.md` (con equazioni in `$ ... $`), `fonti.md`, `verifiche.md`, `LEGGIMI.md` e `manifest.json`.
- Sviluppato `LatexExporter` che applica regole di escaping per non corrompere la compilazione TeX e gestisce i blocchi grafici e matematici chiudendoli nei corretti ambienti (es. `\begin{equation*}`).
- Aggiunto `PdfQaChecker` come mock-engine per ispezionare dinamicamente il layout del documento PDF prima del rilascio all'utente, segnalando overflowing limits (base dell'architettura per il binding in Playwright in M13/M15).

## Quali test sono stati eseguiti
- I test implementati in `packages/didactic/tests/export.test.ts` verificano tre assunti critici:
  - Lo scarico Markdown genera esattamente l'albero di 5 file virtuali previsto, integrando figure in stile standard Markdown.
  - Lo scarico LaTeX converte il body text sfuggendo ai simboli (es. `\%`, `\&`), mentre preserva fedelmente il blocco `f.latex` generato dall'LLM.
  - Il mock `PdfQaChecker` reagisce positivamente a un documento intatto e negativamente sollevando un *overflow issue* se i metadati indicano difetti geometrici.
- L'intera test suite del workspace (34/34 test) è completata con successo.

## Cosa resta aperto

- La generazione fisica via Puppeteer/Playwright del PDF richiede che ci sia un server web attivo (sempre delegato a M13).
