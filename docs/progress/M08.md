# Resoconto M08 - SVG di Base

## Cosa funziona davvero
- Il pacchetto `packages/visual` esporta i contratti di base `visual.ts` attraverso il package `contracts`.
- È possibile utilizzare il `SafeMathEvaluator` per generare punti (x, y) sicuri, escludendo operazioni pericolose, assegnazioni, e supportando discontinuità analitiche.
- Il sistema isola correttamente e valuta le espressioni supportate.
- Il `SvgSanitizer` intercetta e blocca gli SVG con tag `script` e handler nativi `on*`, prefixando in modo affidabile gli `id` e le referenze interne (`url(#id)`).
- Sono implementati i renderer mock per Function Plot (reale), Concept Map e XY Plot.
- `VisualCompiler` integra registry, rendering e sanitizzazione restituendo un SVG finale sicuro.

## Test eseguiti
Tutti i test nel file `packages/visual/tests/visual.test.ts` sono stati completati con successo:
- **SafeMathEvaluator**: verifica dell'esecuzione corretta su logaritmi, verifica del comportamento sulle discontinuità `1/x`, verifica blocco assegnazioni e blocco funzioni javascript globali/non-matematiche (es. evaluate, import).
- **SvgSanitizer**: verifica corretta prefissazione di id e url referenziati; blocco script tag e blocco attributi onload.
- **VisualCompiler**: esecuzione di una end-to-end pipe `SemanticModel -> Render -> Sanitize`.

## Blocchi o problemi aperti
- I renderer del Concept Map e dello XY Plot sono attuali stub implementativi (mock minimali) e dovranno essere estesi in iterazioni o milestone future, qualora richiesto.
- Attualmente le dimensioni del rendering sono un mapping lineare e manca un supporto ad assi non lineari o griglie più avanzate.
