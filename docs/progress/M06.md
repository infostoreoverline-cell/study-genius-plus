# M06 - Fonti e Ingestione (Completato)

## Cosa funziona davvero
- Il pacchetto `packages/ingestion` è stato implementato. 
- `BaseParser` offre i metodi per hashing, text normalization e rilevamento anomalie naive.
- `PdfParser` utilizza `pdf-parse` e supporta l'estrazione paginata.
- Il database schema è stato esteso con le tabelle `sources` e `source_pages` nella migrazione `002_sources.sql`. (NOTA: ho ridenominato la vecchia dipendenza `source_units` della migrazione 001 per non creare conflitti con la nuova implementazione).
- Il router Express `/api/sources` gestisce il caricamento file multipart tramite `multer`. I file vengono poi deduplicati usando `BlobStore` (creato in M04), processati con il `PdfParser` e persistiti in `sources` / `source_pages`.
- È stata creata l'interfaccia utente in React (`apps/frontend/src/pages/Sources.tsx`) per visualizzare ed effettuare l'upload di documenti (mockando attualmente test-project).

## Test eseguiti
- Unit test di `PdfParser` in `packages/ingestion/tests/pdf_parser.test.ts`
- Integration test del router API in `apps/server/tests/sources.test.ts`
- Migrazioni database testate (`npm run test:unit`) con esito positivo e idoneo per le transazioni (nessun blocco per la concorrenza con chiavi estranee).

## Cosa resta aperto
- Supporto a formati addizionali rispetto ai soli PDF (es. ePub, Docx) da estendere in `ingestion` (come indicato nella roadmap).
- Interfaccia React da collegare al router principale e integrare effettivamente con l'autenticazione quando questa verrà implementata (attualmente hardcodato per `test-project`).
- La logica di OCR e validazione avanzata delle anomalie.

Il modulo M06 è completato e testato nelle sue funzionalità base. **M07 (Provider DeepSeek)** è pronto per iniziare.
