# M07 - Appunti e Metodo (Didattica)

## Cosa funziona davvero
- Il package `didactic` espone il `PromptCompiler`, il `Validator` e il `DidacticGenerator`.
- L'enumerazione `DidacticMode` e i profili materia (`SubjectProfile`) sono stati implementati.
- Il sistema compone il prompt iniettando dinamicamente requisiti e profilo materia selezionato.
- In caso di assenza di blocchi essenziali (es. test critico "Solo Gauss"), il `Validator` rileva il problema sollevando *findings* di gravità `CRITICAL`.
- Il `DidacticGenerator` incapsula la logica retry-on-failure iterando la chiamata tramite `AiGateway` e iniettando le direttive di riparazione (`repair instructions`) in base ai findings del `Validator`, restituendo infine un documento revisionato e il suo `hash` (o bloccandosi con stato `NEEDS_REVIEW`).
- La rotta `apps/server/src/http/routes/didactic.ts` è stata creata ed espone in mock la risoluzione dei profili e dei modi didattici per avviare il piano formativo.

## Test eseguiti
1. `npm run test:unit`: I test implementati all'interno di `packages/didactic/tests/didactic.test.ts` sono passati tutti con successo:
   - Composizione corretta del prompt in base a requisiti ed evidenze (`Compiler > should merge prompt elements correctly`).
   - Individuazione corretta della mancanza di requisiti attesi nel testo generato (`Validator > should return critical finding if generated text lacks requirements`).
   - Fallimento strutturale sul mock in assenza totale di elaborazione (`Validator > should fail structurally for "Solo Gauss" fixture`).
   - Verifica di retry automatico ed eventuale etichettatura per revisione umana (`Generator > should attempt repair on failure and eventually mark NEEDS_REVIEW`).

## Elementi ancora aperti
